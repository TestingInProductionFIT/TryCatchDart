# {TryCatch} Ground Station — Modern Modular UI

## Overview
Replace the current placeholder dashboard with a shadcn-inspired light-mode UI: top bar (logo + connection + recording controls + hamburger menu), a workspace-based widget dashboard (12-col drag & resize grid), settings screen (launch site presets), and recorded-flights screen with replay. Everything data-driven and modular.

## 1. Wire format & simulator (`packages/serial`)
The 31-byte payload is dropped for a new made-up, documented format (~54 bytes, big-endian, CRC16-CCITT protected, version byte so it can evolve):

`version(1) · flags(1) · seq(2) · gpsLat i32 1e-7° · gpsLon i32 1e-7° · gpsAlt i32 cm · baroAlt i32 cm · velN/E/D i16 cm/s · accelXYZ i16 mg · gyroXYZ i16 mdps · heading u16 0.01° · roll/pitch/yaw i16 centideg (rocket-side fused attitude) · batteryV u16 mV · hall u8 · fsmState u8 · CRC16(2)`

New files:
- `telemetry/telemetry_frame.dart` — immutable decoded frame model + `FsmState` enum (IDLE, ARMED, BOOST, COAST, APOGEE, DROGUE, MAIN, LANDED, FAULT)
- `telemetry/frame_codec.dart` — encode/decode + layout constants (single source of truth)
- `telemetry/flight_simulator.dart` — pure-Dart flight sim (pad → motor burn few s → coast → apogee → drogue → main → landing drift): kinematics for altitude/velocity/accel, GPS with slow drift, gyro rates, battery drain, hall wire break at apogee, FSM transitions; `MockSerialPort` emits encoded frames at ~10 Hz
- `worker/protocol.dart` — add `SendBytesCommand(Uint8List)` (control panel); worker forwards via existing `SerialService.sendBytes`
- `packet_parser.dart` — new payload length, CRC verification (bad frames dropped)

Attitude ships as Euler in the packet (format is made-up anyway); if firmware later sends raw-only, a ground-side estimator slots into `lib/src/estimation/`.

## 2. Theme (`lib/theme/`)
shadcn-like light Material 3 theme: zinc/neutral palette, white cards with 1px zinc-200 borders, radius 12, near-black primary, high-contrast zinc-900 text (sunlight readability — no large low-contrast areas). Reusable primitives: `AppCard`, section headers, filled/outline buttons, status pills. Bundle Inter font if downloadable, else platform font fallback.

## 3. App shell (`lib/app/`)
- `top_bar.dart` — logo + "{TryCatch} · Testing in Production" wordmark left; center-right: port picker/connect (absorbs `serial_toolbar`), packet-rate pill (uses existing `PacketRateTracker`), record button + duration/file (absorbs `recording_toolbar`); hamburger top-right
- `app_shell.dart` + `router.dart` — hamburger menu opens drawer: Dashboard, Recorded Flights, Raw Monitor (kept for debugging), Settings; simple Riverpod screen switcher (3 screens, no router dep). Recording controls always visible regardless of screen (recording is global).

## 4. Telemetry core (`lib/src/telemetry/`, `lib/src/estimation/`)
- `telemetry_store.dart` — Riverpod Notifier (single ingestion point): decodes packets → `TelemetryFrame`, keeps `latestFrame`, ring-buffer history per signal (altitude, velocities, accelerations, battery, packet rate) with time windowing, derived stats (max altitude, distance from launch site, apogee time), works for both live and replay sources
- `estimation/dead_reckoning.dart` — pure class: integrates NED velocity from last GPS fix → DR lat/lon/alt (own unit tests; fully decoupled per your request)

## 5. Workspace system (`lib/workspaces/`)
- `workspace_models.dart` — `Workspace`, `WidgetPlacement {typeId, x, y, w, h}` grid rects; JSON round-trip; persisted per-workspace in `shared_preferences`
- `placement_logic.dart` — pure, tested functions: no-overlap invariant via position swap, resize clamping, bounds checks
- `workspace_grid.dart` — custom render (Stack + fractional-width Positioned), drag to move (hover slot preview), corner drag to resize, edit-mode toggle, add-widget catalog drawer, per-widget remove
- `workspace_controller.dart` — workspaces CRUD, active workspace, rename/duplicate/delete, default layout factory
- Workspace tabs directly under top bar, instant switching, keyboard shortcut (e.g. Ctrl+1..9)
- `widget_registry.dart` — data-driven registry: `{typeId, title, minSize, defaultSize, builder}`; "Add widget" picker and default layouts are generated from it — a new widget is one file + one registry entry

## 6. Dashboard widgets (`lib/workspaces/widgets/`)
All read from `TelemetryStore`/registry; shared styling from `AppCard`:
- `stats_widget.dart` — GPS coords+alt, DR coords+alt, max height, horizontal distance from launch site
- `time_series_chart.dart` — one shared configurable fl_chart wrapper (series: label, color, extractor, unit) → thin configs for **altitude**, **velocity** (horizontal + total + dashed vertical), **acceleration** (horizontal + total), **battery**
- `fsm_widget.dart` — config-driven state list (id → name/color), prominent current state + time in state
- `hall_sensor_widget.dart` — big readout, intact/broken badge, sparkline
- `control_panel_widget.dart` — data-driven `ControlAction {label, bytes, danger}` catalog; click → "ARM?" confirm state → second click within timeout sends `SendBytesCommand`
- `map_widget.dart` — flutter_map + OSM tiles: launch-site marker (from settings), GPS track polyline + live marker, DR track polyline + marker (tiles need internet; offline cache noted as future work)
- `rocket_3d_widget.dart` — CustomPainter 3D projection (no extra deps, no webview): simple rocket mesh (nose, body, fins) rotated by packet attitude; parachute canopy visualization in DROGUE/MAIN states

## 7. Settings (`lib/settings/`)
Launch site editor (label, lat, lon, alt) with preset save/load/delete, persisted via `shared_preferences`; used by map + stats. Also "reset workspaces to default".

## 8. Recorded flights (`lib/flights/`)
List recordings from `Documents/TryCatch/recordings` (parse 12-byte chunk headers for duration/size), replay button streams `FileParser` output into `TelemetryStore` in replay mode with play/pause/speed (1×/4×/max) — full dashboard works on recorded flights. Note: old 31-byte recordings are incompatible with the new parser (format not finalized — acceptable).

## 9. Cleanup
Old toolbars (`serial_toolbar`, `recording_toolbar`, `telemetry_metrics_toolbar`) absorbed into top bar; `raw_byte_monitor` moves under the hamburger menu; `dashboard.dart` replaced by the shell. Existing behavior (worker spawn override, tray, window lifecycle) untouched.

## 10. Tests
Codec round-trip + CRC rejection; parser with new framing; flight simulator plausibility (alt ≥ 0, phase ordering); dead-reckoning drift bounds; placement logic; workspace/settings JSON round-trips. Update existing `packet_parser_test` for new payload length.
